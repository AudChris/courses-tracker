WORK FLOW การใช้งาน BU Course Tracker
=====================================

1. เริ่มต้นใช้งาน
   - เปิดเว็บไซต์
   - หากยังไม่มีบัญชี ให้เลือก "สมัครสมาชิก"
   - หากมีบัญชีแล้ว ให้เลือก "เข้าสู่ระบบ"
   - สามารถเข้าสู่ระบบด้วยบัญชี Google ได้

2. สมัครสมาชิก
   - กรอกชื่อจริง นามสกุล คณะ และสาขา
   - กรอกอีเมลและรหัสผ่านอย่างน้อย 6 ตัวอักษร
   - กรอกรหัสผ่านยืนยันให้ตรงกับรหัสผ่าน
   - กด "สร้างบัญชี"
   - หากระบบแจ้งให้ยืนยันบัญชี ให้เปิดอีเมลและกดลิงก์ยืนยันก่อนเข้าสู่ระบบ

3. เข้าสู่ระบบ
   - กรอกอีเมลและรหัสผ่าน แล้วกด "เข้าสู่ระบบ"
   - หรือเลือกเข้าสู่ระบบด้วย Google
   - หากลืมรหัสผ่าน ให้กรอกอีเมลแล้วเลือก "ลืมรหัสผ่าน?"
     จากนั้นเปิดอีเมลเพื่อทำตามลิงก์รีเซ็ตรหัสผ่าน

4. หน้า Dashboard
   - เมื่อเข้าสู่ระบบสำเร็จ ระบบจะแสดงภาพรวมการเรียน
   - ตรวจดูจำนวนวิชาและหน่วยกิตแยกตามสถานะ พร้อม Progress จากวิชาที่บันทึกไว้
     (ไม่ใช่หน่วยกิตรวมตามหลักสูตร)
   - ดูรายการวิชาที่กำลังเรียน ยังไม่ได้เรียน และวิชาที่เพิ่มล่าสุด
   - GPA คำนวณจากวิชาที่เรียนแล้วและมีเกรด A-F โดยถ่วงน้ำหนักตามหน่วยกิต
     และไม่นับเกรด S/U; หากไม่มีเกรดที่ใช้คำนวณ ระบบจะแสดงคำแนะนำแทน 0.00
   - ค้นหาและกรองรายวิชาตามสถานะ ชั้นปี ภาคเรียน และหมวดวิชา
   - บนโทรศัพท์ใช้แถบนำทางด้านล่างเพื่อไปยังรายการวิชา สถิติ และโปรไฟล์
   - หากข้อมูลนักศึกษายังไม่ครบ ระบบจะแสดงหน้าต่างให้กรอกข้อมูล
   - เลือก "แก้ไขข้อมูล" เพื่อแก้ชื่อ นามสกุล คณะ สาขา หรือรูปโปรไฟล์
   - รูปโปรไฟล์รองรับ JPG, PNG และ WebP ขนาดไม่เกิน 5 MB

5. เพิ่มรายวิชา
   - เลือก "เพิ่มรายวิชา" จากเมนูหรือปุ่มในรายการรายวิชา
   - กรอกรหัสวิชา ชื่อวิชา หน่วยกิต หมวดวิชา ชั้นปี และภาคเรียน
   - เลือกสถานะเริ่มต้นของวิชา
   - เกรดและหมายเหตุเป็นข้อมูลเพิ่มเติม ไม่จำเป็นต้องกรอก
   - กด "บันทึกรายวิชา" เพื่อกลับไปยัง Dashboard
   - รหัสวิชาที่มีอยู่ในบัญชีแล้วจะไม่สามารถเพิ่มซ้ำได้

6. ติดตามและแก้ไขสถานะวิชา
   - ใช้ช่องค้นหาเพื่อค้นหาด้วยรหัสหรือชื่อวิชา
   - เปลี่ยนสถานะจากรายการ "สถานะ" ได้โดยตรง
   - เปลี่ยนเกรดจากรายการ "เกรด" ในแถวรายวิชาได้โดยตรง
   - เลือกช่อง "เรียนแล้ว" ด้านหน้ารายวิชาเพื่อเปลี่ยนสถานะเป็นเรียนแล้ว
   - เมื่อนำเครื่องหมายออก สถานะจะกลับเป็นยังไม่ได้เรียน
   - จำนวนวิชาและหน่วยกิตใน Dashboard จะอัปเดตตามสถานะล่าสุด

7. ลบรายวิชา
   - กดปุ่มรูปถังขยะท้ายแถวของรายวิชาที่ต้องการลบ
   - ตรวจสอบชื่อวิชาในหน้าต่างยืนยัน แล้วเลือกยืนยันการลบ
   - การลบไม่สามารถย้อนกลับได้

8. ออกจากระบบ
   - เลือก "ออกจากระบบ" ที่เมนูด้านข้าง
   - เมื่อออกจากระบบสำเร็จ ระบบจะกลับไปหน้าเข้าสู่ระบบ


WORK FLOW สำหรับผู้ดูแล: เผยแพร่เว็บไซต์บน Firebase Hosting
============================================================

1. เปิด Terminal หรือ PowerShell ที่โฟลเดอร์โปรเจกต์
2. สร้างไฟล์สำหรับเผยแพร่ด้วยคำสั่ง:
      npm run build
3. เผยแพร่โฟลเดอร์ dist ไปยัง Firebase Hosting ด้วยคำสั่ง:
      firebase deploy --only hosting --project ce481-bb7ef
4. รอจนคำสั่งแจ้งว่า Deploy สำเร็จ
5. เปิด URL ของ Firebase Hosting และรีโหลดหน้าแบบไม่ใช้แคช
   (Ctrl+F5) เพื่อตรวจเวอร์ชันล่าสุด
