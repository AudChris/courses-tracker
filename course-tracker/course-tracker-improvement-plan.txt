ข้อเสนอแนะการพัฒนาเว็บ Course Tracker
เว็บ: https://ce481-bb7ef.web.app/dashboard

มุมมอง: จำลองเป็น USER ที่ล็อกอินเข้ามาใช้งานจริงทุกวัน

==================================================
1. ภาพรวมการเรียน
==================================================

ควรมีส่วนที่ตอบคำถามทันทีว่า “ตอนนี้เรียนไปถึงไหนแล้ว?”

ตัวอย่าง:
- ความคืบหน้าการเรียน 78%
- เรียนแล้ว 94 / 120 หน่วยกิต
- ยังไม่ได้เรียน 20%
- กำลังเรียน 12%

แนะนำให้มี Progress Bar ที่เด่นบริเวณด้านบน Dashboard

==================================================
2. เพิ่ม “วิชาที่กำลังเรียน”
==================================================

ควรแสดงวิชาที่มีสถานะกำลังเรียน พร้อม Progress

ตัวอย่าง:
- CS101 Programming — 80%
- DB201 Database — 50%
- UX101 User Experience — 30%

มีปุ่ม “ดูวิชาทั้งหมด”

==================================================
3. เพิ่ม “วิชาที่ยังไม่ได้เรียน”
==================================================

เป็น Feature สำคัญสำหรับเว็บเช็ควิชาที่เรียนแล้ว/ยังไม่ได้เรียน

แสดงจำนวนวิชาที่ยังไม่ได้เรียน เช่น:
- ยังไม่ได้เรียน 12 วิชา

แสดงตัวอย่าง 3-5 วิชา:
- Database System
- Computer Network
- Software Engineering

มีปุ่ม “ดูทั้งหมด”

==================================================
4. เพิ่ม “วิชาที่เรียนล่าสุด”
==================================================

แสดง Activity ล่าสุดของผู้ใช้ เช่น:
- Database System — เรียนแล้ว — 5 นาทีที่แล้ว
- Web Programming — เรียนแล้ว — เมื่อวาน
- Computer Network — กำลังเรียน — 2 วันที่แล้ว

ช่วยให้เว็บดูเป็น Application จริงมากกว่า CRUD Dashboard

==================================================
5. เพิ่ม GPA
==================================================

ถ้ามีเกรด ควรคำนวณ GPA อัตโนมัติ

ตัวอย่าง:
GPA ปัจจุบัน: 3.42 / 4.00

สามารถแสดง GPA แยกตามปี:
- ปี 1: 3.21
- ปี 2: 3.45
- ปี 3: 3.58
- ปี 4: 3.62

ถ้ายังมีข้อมูลเกรดไม่เพียงพอ ให้แสดง:
“เพิ่มเกรดของวิชาเพื่อคำนวณ GPA”

ไม่ควรแสดง 0.00 หากผู้ใช้ยังไม่มีเกรด

==================================================
6. เพิ่ม “หน่วยกิตที่เหลือ”
==================================================

ตัวอย่าง:
หน่วยกิต
94 / 120

เรียนแล้ว: 94
เหลือ: 26

สามารถแยกตามหมวด:
- หมวดทั่วไป: 30 / 30
- วิชาเอก: 45 / 60
- วิชาเลือก: 12 / 18
- วิชาเสรี: 7 / 12

==================================================
7. เพิ่ม “วางแผนเทอมถัดไป”
==================================================

Feature นี้ช่วยยกระดับเว็บจากระบบเช็ควิชาเป็นระบบวางแผนการเรียน

ตัวอย่าง:
ปี 3 / เทอม 2

- Database
- Software Engineering
- Network
- Mobile Application

รวม 12 หน่วยกิต

ปุ่ม:
“+ เพิ่มวิชา”

==================================================
8. ปรับ Search และ Filter
==================================================

ควรใช้งานง่ายและเข้าถึงเร็ว

ปุ่มสถานะ:
[ทั้งหมด] [เรียนแล้ว] [กำลังเรียน] [ยังไม่ได้เรียน]

Filter:
- ปีการศึกษา
- เทอม
- หมวดวิชา

Search:
“ค้นหารหัสหรือชื่อวิชา...”

ควรมีปุ่ม:
“ล้างตัวกรอง”

1. ตอนนี้ฉันเรียนไปถึงไหนแล้ว?
2. ฉันยังขาดอะไร?
3. ฉันควรทำอะไรต่อ?

“Course Planner + Graduation Progress”

“ระบบเช็ควิชาที่เรียนแล้ว”
ให้เป็น
“ระบบติดตามและวางแผนการเรียนส่วนตัว”
